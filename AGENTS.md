# Contributor boundary

Write public material in English. This is a generic engine, not a project archive.

Never import customer files, brand details, account data, invoices, private paths, real prompts, generated media or credentials. Create synthetic fixtures in temporary directories. Keep private production workspaces outside this repository and all Git worktrees. Do not replace absent evidence with invented success or cost values.

Use explicit file staging. Review the exact diff and history before publishing. Update the exact allowlist deliberately; adding a path does not make its content safe. Run the tests and release scanner. Do not print secret matches or provider payloads. Do not add network calls, paid generation or dependencies to the smoke test.

Keep technical verification, creative acceptance, rights and client approval separate. Document adapter limitations and require an explicitly chosen provider before any external operation. Never auto-publish customer output.
