# Controlled commercial pilot

Sell a measured, repeatable service with a bounded first pilot. Agree the product, variants, placements, message, input artwork, source rights, number of revisions and acceptance owner before quoting. Do not promise an unmeasured turnaround, cost advantage or ad-performance uplift.

The pilot should prove one faithful product master, useful ad communication, a format adaptation, an intentional revision and an intact handover. Report setup effort separately from repeat production. Define what is included in one asset: a new concept, a crop and a copy variant are different work units.

Benchmark against the customer's current process using the same brief and acceptance criteria. Record time to accepted output, rejected attempts, total provider consumption and revision time. Quality includes message clarity and category evidence as well as material realism.

Any ad experiment needs an agreed control, audience, placement, spend, attribution window and minimum evidence threshold. CTR and CPA are business outcomes to measure, not guarantees from an image-generation pipeline. Avoid causal claims from an uncontrolled small test.

Use the private contract to state price, delivery schedule, rights, approval responsibilities, support and excluded work. MIT makes this framework available for commercial use but does not supply customer assets, provider subscriptions, production support or a warranty.
